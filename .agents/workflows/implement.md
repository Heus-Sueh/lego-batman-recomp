# Implement

Implement the requested feature using incremental verified changes.

1. Understand the existing implementation.

2. Identify the smallest integration point.

3. Search for similar code in the repository.

4. Consult relevant skills and references.

5. Define observable success criteria.

6. Implement the smallest useful change.

7. Build.

8. Run relevant tests.

9. Validate actual behavior.

10. Continue incrementally until the requested behavior is complete.

After implementation:

- remove accidental duplication
- remove temporary debugging code
- update relevant documentation
- report remaining unknowns

Do not perform unrelated refactors.
