# Finish Task

Before declaring a task complete:

1. Review the original request.

2. Verify every requested behavior.

3. Build the affected project.

4. Run relevant tests.

5. Perform runtime validation when applicable.

6. Check for:
   - temporary debugging code
   - accidental files
   - TODOs introduced by the task
   - duplicated implementation
   - unrelated modifications

7. Update documentation when durable knowledge was discovered.

8. Record unresolved questions.

9. Summarize:
   - what changed
   - how it was validated
   - remaining limitations

Do not declare completion while required behavior remains UNKNOWN.
