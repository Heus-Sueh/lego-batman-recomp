# Research

Investigate a technical question before implementation.

1. Define the exact question.

2. Inspect the repository first.

3. Inspect project documentation.

4. Inspect relevant skills.

5. Identify maintained reference implementations when available.

6. Compare references against the current architecture.

7. Separate findings into:

   VERIFIED
   PARTIALLY_VERIFIED
   INFERRED
   UNKNOWN

8. Record:
   - findings
   - evidence
   - relevant references
   - architectural implications
   - unresolved questions

9. Persist durable project-specific findings under docs/.

Research should reduce uncertainty enough to enable a concrete next action.
