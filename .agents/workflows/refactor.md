# Refactor

Improve internal structure without intentionally changing behavior.

1. Define the structural problem.

2. Demonstrate that the problem actually exists.

3. Identify behavior that must remain unchanged.

4. Establish validation before modification.

5. Make the smallest structural change.

6. Build and test after each meaningful step.

7. Compare behavior before and after.

8. Remove obsolete code only after proving it is no longer required.

Do not combine refactoring with unrelated feature work.

Do not introduce abstractions solely because they may be useful someday.
