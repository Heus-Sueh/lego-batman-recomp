# Start Task

Prepare the repository for a new task.

1. Read the request carefully.

2. Inspect:
   - AGENTS.md
   - relevant rules
   - relevant skills
   - relevant documentation

3. Locate the code involved.

4. Search for existing implementations related to the task.

5. Identify:
   - desired outcome
   - affected components
   - dependencies
   - constraints
   - validation method

6. Determine what is known and unknown.

7. Break the task into the smallest useful verifiable milestones.

8. Identify blockers before implementation.

9. Begin with the first milestone.

Do not create a large speculative implementation plan when the repository
can provide the answers directly.
