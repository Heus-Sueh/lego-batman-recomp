## First recovered function

Without automatic bridges the first observed missing target was 0x0073D482,
called from __tmainCRTStartup (0x0073D4C3). Inspection established a 65-byte leaf
checking DOS/PE32 headers and the CLR data directory. Two plain returns occur
at 0x0073D4BF and 0x0073D4C2. Call site 0x0073D588 supplies no arguments and
stores EAX immediately afterward. The zero-argument cdecl label remains
PARTIALLY_VERIFIED; no second independent call site was established.

The function is now declared in functions.toml and regenerated by `just lift`.
VERIFIED: build passes, registered count increases to 49 and natural entry
execution passes the former blocker. The next unresolved-call register report
has EAX=0, consistent with this unmanaged PE check. This is targeted runtime
evidence, not full ABI or behavioral equivalence certification.

## Validation and limitations

VERIFIED: generation/build and entry (Level 3). Four runtime foundation tests
and two driver-policy tests passed. The policy tests include the legacy profile
as a control that exposes an automatically discovered bridge. The new strict
frontier test checks nonzero exit, caller/target and one unresolved event.

The full suite before the counter fix ran 27 tests: 10 passed, 11 failed, six
legacy-only probes skipped. The boot tests now fail at the exposed CRT gap;
their success assertions have deliberately not been weakened. They are required
future completion checks, not currently satisfied regressions. The old 27-reached
message-loop baseline no longer applies to the strict profile.

The generated unresolved callback previously did not increment DispatchTable's
coverage counter. It now logs through the same event-counting path, and the
adapter emits coverage/frontier even on exception exits. A printed zero counter
in older reports did not rule out a generated unresolved call.

The lift cache now includes target/revision manifests, the original binary and
all analysis Python sources so adapter or generator edits invalidate it. No
proprietary data or generated source was added to version control.
